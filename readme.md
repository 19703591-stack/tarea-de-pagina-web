#  Mantenimiento y Aseguramiento del Sistema Informático

Página web informativa sobre mantenimiento de sistemas informáticos, desarrollada como recurso académico con apoyo de IA (Claude by Anthropic).

##  Archivos
| Archivo | Descripción |
|---|---|
| `index.html` | Estructura HTML con navegación y 6 secciones |
| `style.css` | Estilos, animaciones y diseño responsivo |
| `README.md` | Documentación del proyecto |

##  Secciones
Inicio · Tipos · Herramientas · Procedimientos · Seguridad · Contacto

##  Tecnologías
HTML5 · CSS3 · JavaScript · Google Fonts (Space Mono + Outfit)

##  Uso
Abre `index.html` en cualquier navegador. No requiere servidor ni dependencias.

##  Commits
1. `README.md` — Documentación inicial
2. `style.css` — Hoja de estilos
3. `index.html` — Página completa
