// 01 — Clasificación

Tipos de Mantenimiento

Cada tipo cumple una función específica dentro del ciclo de vida del sistema informático.

Preventivo 🛡️

Mantenimiento Preventivo

Acciones programadas para prevenir fallos: limpieza de hardware, actualizaciones, revisión de logs y respaldos periódicos.

  • Limpieza física de componentes
  • Actualización de antivirus y SO
  • Verificación de copias de seguridad
  • Monitoreo de temperatura
Correctivo 🔧

Mantenimiento Correctivo

Intervención ante fallos ocurridos. Puede ser inmediato (crítico) o diferido (no urgente).

  • Diagnóstico de la falla
  • Reemplazo de componentes
  • Restauración desde backups
  • Pruebas post-reparación
Predictivo 📊

Mantenimiento Predictivo

Monitoreo continuo con métricas y sensores para anticipar posibles fallos antes de que se produzcan interrupciones.

  • Análisis S.M.A.R.T. en discos
  • Monitoreo de temperatura
  • Análisis de tendencias
  • Alertas por umbrales
Evolutivo 🚀

Mantenimiento Evolutivo

Actualizaciones y mejoras estratégicas para satisfacer nuevos requerimientos funcionales, tecnológicos o de seguridad.

  • Migraciones de plataforma
  • Actualización de arquitectura
  • Nuevas funcionalidades
  • Optimización de procesos

Procedimientos de Mantenimiento

Protocolo estándar para ejecutar un mantenimiento integral y documentado.

01

Planificación y Programación

Definir alcance, sistemas afectados, ventana de mantenimiento y checklist de actividades para minimizar impacto en usuarios.

⏱ 2-4 horas👤 Admin TI📋 Documentar
02

Respaldo y Verificación de Datos

Realizar copias de seguridad completas y verificar su integridad restaurando una muestra en entorno de pruebas.

⏱ 1-6 horas🔴 Crítico✅ Verificar backup
03

Diagnóstico del Sistema

Ejecutar herramientas para evaluar estado de hardware (disco, RAM, CPU) y software (logs, servicios, recursos). Documentar hallazgos.

⏱ 30-90 min🔍 Análisis📸 Capturas
04

Ejecución de Tareas

Limpieza física, actualización de SO y software, optimización de BD, revisión de permisos y políticas de seguridad.

⏱ Variable🔧 Intervención📝 Registro
05

Pruebas y Verificación

Comprobar que sistemas críticos operan correctamente: pruebas de carga, conectividad, servicios y acceso de usuarios.

⏱ 1-2 horas✅ Validación👥 Usuarios
06

Documentación y Cierre

Registrar fecha, duración, técnico, hallazgos, acciones y estado final. Programar el próximo mantenimiento preventivo.

⏱ 30-60 min📄 Informe📅 Próximo mtto.
// 04 — Aseguramiento

Seguridad y Aseguramiento del Sistema

Medidas técnicas y administrativas para proteger la integridad, confidencialidad y disponibilidad del sistema.

🔄

Parches y Actualizaciones

Aplicar actualizaciones de seguridad oportunamente. Las vulnerabilidades conocidas son el vector de ataque más común.

🔐

Control de Acceso y Privilegios

Principio de mínimo privilegio: cada usuario y servicio debe tener solo los permisos estrictamente necesarios.

🔑

Cifrado de Datos

AES-256 para datos en reposo y TLS 1.3 para comunicaciones. Proteger especialmente credenciales y datos sensibles.

👁️

Monitoreo y Auditoría de Logs

Implementar SIEM para centralizar y analizar eventos del sistema, detectando comportamientos anómalos en tiempo real.

📋

Plan de Contingencia (DRP)

Mantener un Disaster Recovery Plan actualizado y probado. Definir RTO y RPO para cada sistema crítico.

⚠️

Amenazas Comunes

Vectores de ataque más frecuentes en entornos corporativos
  • CRÍTICO
    RansomwareCifra archivos del sistema y exige rescate. Puede paralizar operaciones completas.
  • ALTO
    Phishing / Ingeniería SocialSuplantación de identidad para obtener credenciales de acceso a sistemas.
  • ALTO
    Vulnerabilidades Sin ParcheSoftware desactualizado explotable remotamente sin interacción del usuario.
  • MEDIO
    Amenazas InternasEmpleados con acceso que pueden filtrar o sabotear información intencionalmente.
  • MEDIO
    Ataques DDoSSaturación de recursos del servidor causando denegación de servicio.
